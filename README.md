# Text Repeater

Minimalist ve mobil uyumlu metin tekrarlayıcı. Tekrarlama sayısını, ayırıcıyı ve simge/numara/ters çevirme seçeneklerini belirleyip metninizi anında oluşturabilir, karakter ve kelime sayısını görebilir, sonucu kopyalayabilirsiniz.

## Kullanım

`index.html` dosyasını tarayıcınızda açmanız yeterlidir. Uygulama HTML, CSS ve JavaScript'i tek dosyada içerir; herhangi bir kurulum ya da bağımlılık gerektirmez.
